Privacy, in plain language

Your family archive stays on your computer. The website never asks to open it.

CLI data

The CLI reads only the folders and files you name. It writes reports only inside the output folder you choose.

It has no analytics, account system, or network feature. It does not upload photos, names, hashes, policies, or reports.

Website data

The website uses no analytics, advertising, cookies, or third-party scripts. It does not ask for a folder or accept photo uploads.

The sample page uses bundled fixture data. It does not read or save your family data.

Your choices

Delete a CLI report whenever you no longer need it. Uninstalling the CLI removes the program.

Reports can include filenames and device-owner names. Store them with the same care as your archive.

Contact

For privacy questions, open an issue in the public source repository.
